# FactLens SDK and CLI v6.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release FactLens NPM v6.5.0 with current Verify response/input parity, exact verdict colors, developer-token API-key customization management, monotonic timing, and a forward-only CLI progress experience.

**Architecture:** Extend the existing developer-token platform with project/key-owned customization REST routes that reuse the current API-key customization tables and shared normalization contract. In the NPM package, add a typed `client.keys.customization` resource, expand Verify types/CLI input parity, and replace the bouncing progress cursor with a TTY-only forward phase rail plus truthful non-TTY activity output. Preserve existing APIs unless explicitly extended.

**Tech Stack:** TypeScript, Node.js 18+, Deno/Supabase Edge Functions, GitHub Actions, Node test runner.

## Global Constraints

- Release version is exactly `6.5.0`.
- Modify Factlens-API only for developer-token customization routing and its tests; no Extension, Console, Website/Admin, Support, or unrelated backend changes.
- Modify Factlens-NPM for SDK, CLI, tests, docs, changelog, examples, and release metadata.
- Never invent server progress percentages. Text/image verification uses phase state only; audio upload may show a real byte-derived percentage.
- Interactive TTY progress moves forward only. Non-TTY output uses phase lines rather than carriage-return animation.
- Existing `RequestOptions.timeout` remains milliseconds and backward compatible. Add `timeoutSeconds`; supplying both is a configuration error.
- Progress events retain `elapsedMs` and add `elapsedSeconds` from a monotonic clock.
- CLI adds `--timeout-seconds` and `--time-unit auto|ms|s` while preserving `--timeout` milliseconds.
- Human Verify output uses the API-provided `verdictColor`; `--json` remains machine-readable and unmodified.
- Main branches move only after verification.
