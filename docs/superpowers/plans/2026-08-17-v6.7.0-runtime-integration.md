# FactLens NPM v6.7.0 Runtime Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship FactLens NPM v6.7.0 with precise runtime timing/diagnostics, richer request inspection, advanced audio lifecycle visibility, robust read-only retries, and full compatibility with the unified FactLens API runtime.

**Architecture:** Preserve `client.verify()` behavior while adding a detailed-response path that carries transport/runtime metadata parsed from API headers. Reuse one transport implementation for normal/detailed SDK calls and let the CLI consume the same typed metadata. Keep the v6.5.0 forward-only colored progress design and exact verdict-color behavior.

**Tech Stack:** TypeScript, Node 18/20/22, built-in fetch/AbortController, ANSI terminal rendering, Node test runner.

## Global Constraints

- Package version is exactly `6.7.0`.
- Existing v6.5.0 `verify()` usage remains valid.
- Do not label core verification time as total server time.
- Preserve forward-only colored progress; no fake percentages for text/image.
- Continue exact API `verdictColor` truecolor output and `NO_COLOR` behavior.
- Do not automatically retry billable Verify POSTs or mutations by default.
- New SDK/CLI timing must consume the coordinated API `Server-Timing` contract.
- Do not publish to npm until the coordinated API runtime is verified and the user explicitly chooses to publish.

- [ ] **Step 2: Implement parser**

Never throw for malformed/missing header.

- [ ] **Step 3: Implement metadata builder**

```ts
export function buildResponseMeta({ headers, clientTotalMs, status, retryCount = 0 }) {
  const serverTiming = parseServerTiming(headers.get('server-timing'));
  const edgeMs = serverTiming.edgeMs;
  return {
    requestId: headers.get('x-request-id') ?? undefined,
    clientTotalMs,
    clientTotalSeconds: clientTotalMs / 1000,
    serverTiming,
    gatewayNetworkMs: Number.isFinite(edgeMs) ? Math.max(0, clientTotalMs - edgeMs) : undefined,
    retryAfterMs: parseRetryAfter(headers.get('retry-after')),
    httpStatus: status,
    retryCount,
  };
}
```
