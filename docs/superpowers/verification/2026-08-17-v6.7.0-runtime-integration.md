## Verified release scope

The v6.7.0 work branch preserves ordinary `client.verify()` usage while adding additive runtime diagnostics and CLI observability for the unified FactLens API runtime.

Implemented release surfaces include:

- package/SDK version `6.7.0`
- `verifyDetailed()` while `verify()` remains the compatibility projection
- typed `Server-Timing` parsing and response metadata
- client total, core/edge, outside-network estimate, retry count, and bounded `Retry-After`
- safe `FactLensError` diagnostics without secret/media leakage
- AbortSignal plus timeout composition/cleanup
- one conservative automatic retry for transient read-only GET operations
- no automatic retry for billable Verify POSTs or mutations
- detailed runtime Usage read without changing `usage.get()` data shape
- audio lifecycle progress metadata without fake completion percentages
- CLI total/core timing, verbose phase timing, `--trace`, and `--time-unit`
- non-billable `factlens doctor`
- request-detail verdict cards without legacy Input/Pipeline presentation
- exact API `verdictColor` handling and `NO_COLOR` compatibility
